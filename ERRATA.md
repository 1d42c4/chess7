# Errata / Corrections

AI can make excellent instructional material, but chess is concrete and errors should be corrected openly.

When a lesson seems wrong, unclear, or misleading, record it here.

| Date | Course | Lesson | Issue | Correction / verification |
|---|---|---:|---|---|
| | | | | |

## Suggested verification process

1. Recreate the exact position.
2. Check tactical legality first.
3. Compare the strategic explanation with a current engine/database if the line is forcing.
4. Correct the lesson rather than merely deleting the uncomfortable position.
5. Record what changed and why.

**Checks, captures, threats, king safety, and concrete calculation override opening rules.**
