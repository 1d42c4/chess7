Open Beginner's Field Guide

How to use the school

1. Study small blocks

Do a few lessons at a time. Diagnose the board before revealing the answer.

2. Play real games

Use the opening and notice the first position where you no longer know the plan.

3. After-action review

Return to the relevant lesson. The GitHub repository includes STUDY_LOG.md and ERRATA.md for personal review and corrections.

4. Verify concrete theory

AI is powerful but not infallible. For serious tournament preparation, verify forcing lines with a current engine/database.
