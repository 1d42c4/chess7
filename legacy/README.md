# Legacy / Earlier Experiments

The public repository currently contains four earlier single-page experiments under `chess-opening-courses/`:

- `hippo-counter-trainer.html`
- `hippopotamus-course.html`
- `kings-indian-course.html`
- `opening-course-library.html`

It also contains `FullCourses/grok-hippo-lessons.zip`.

These predate the current field-manual organization. The modern GitHub Pages site does not depend on them.

If this package is **overlaid onto a clone of the existing repository**, run `organize-existing-repo.sh`; it will move those existing files into this `legacy/` area without deleting them.
